Как это работает

Коротко: что здесь можно менять, что происходит при публикации и что делать, если что-то пошло не так.

1. Что где лежит

  • Цены — ставка за час по каждому дню недели, акции «часы в подарок», праздничный тариф, правила для гостей и скидки. Всё, что вы здесь поменяете, сразу пересчитывается в калькуляторе сайта.
  • Допуслуги — офуро, печь, мангал, веники, полотенца, простыни, комплекты, уголь, стоянка. Каждая строка — карточка на сайте и поле в калькуляторе.
  • Меню — пункты в шапке и в мобильном меню.
  • Фотографии — галерея: загрузка, подписи, категории (кнопки фильтра) и удаление.

2. Как сохранить изменения

Пока вы редактируете, всё хранится в этом браузере как черновик. Кнопка «Предпросмотр» вверху открывает сайт с вашим черновиком — удобно проверить, ничего не публикуя.

Чтобы изменения увидели все посетители, нажмите «Опубликовать». Админка запишет файл assets/data/content.json (и новые фотографии) в репозиторий сайта на GitHub. Через 30–60 секунд GitHub Pages обновит страницу — обновите её с очисткой кеша (Ctrl+F5).

3. Ключ доступа (один раз)

Для публикации нужен ключ GitHub. Он хранится только в вашем браузере и никуда не отправляется, кроме github.com.

  1. Откройте github.com/settings/personal-access-tokens/new.
  2. Название — любое, например «админка бани». Срок — можно «No expiration».
  3. Repository access → Only select repositories → rallkololo-prog/banya-na-turuhtannyh.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  5. Нажмите «Generate token», скопируйте и вставьте в поле ключа в админке (появится при первой публикации).

Ключ можно отозвать в любой момент на той же странице GitHub.

4. Если что-то сломалось

  • «Не удалось опубликовать» — чаще всего истёк ключ или у него нет права Contents: write. Создайте новый и вставьте заново.
  • На сайте старые цены — подождите минуту и обновите страницу с Ctrl+F5, GitHub Pages собирает сайт не мгновенно.
  • Хочу вернуть как было — кнопка «Скачать JSON» сохраняет текущее состояние, а прежние версии файла всегда лежат в истории репозитория на GitHub.
  • Ничего не трогайте в других файлах (index.html, style.css) — для цен, меню и фото админки достаточно.

Публикация на сайт

Нужен ключ GitHub с правом Contents: Read and write на репозиторий сайта. Подробная инструкция — во вкладке «Как это работает».
